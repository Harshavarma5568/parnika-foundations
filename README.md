# Parnika Foundations — Website Demo

A premium, responsive static website prototype for Parnika Foundations, Tadepalligudem.

## Current interactions
- Responsive mobile navigation
- Property category filters
- Property detail modal
- Google Maps project-area embed and directions link
- Enquiry form validation and WhatsApp message handoff
- Reduced-motion support and responsive layouts

## Hosting and data
This is a static frontend suitable for GitHub Pages. The form opens WhatsApp with a prefilled message; the visitor must press Send. The website does not silently save leads, send email, authenticate users, or provide a database/admin dashboard. Those features require a secure backend or third-party service.
